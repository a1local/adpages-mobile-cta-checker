# Privacy

AdPages Mobile CTA Checker is an offline local-file analyzer.

- It reads the local files explicitly passed through `--html-file`.
- It does not make network calls.
- It does not crawl websites.
- It does not collect analytics.
- It does not store, transmit, or sell page content.
- It does not require API keys, account credentials, cookies, or browser sessions.

Reports are written to standard output only unless the user redirects output in their own shell.
