# Publish Blockers

Resolve these before any npm, marketplace, or public directory submission:

- Confirm npm scope ownership and final package name before registry publication.
- Add final terms URL if paid/hosted features are added.
- Decide whether the sample report should show a mostly-passing page, a deliberately flawed page, or both.
- Add screenshots or a short demo GIF if the target directory expects visual proof.
- Validate the wording against the final AdPages product positioning.
- Confirm pricing and upsell path for any future hosted batch checker or branded report feature.
- Run `npm run check`, `npm run smoke`, and `npm pack --dry-run` from this package before release.
- MIT license and public GitHub repository metadata are now set for source publication.
